# Лабораторная работа: Обработка строковых данных в Python

## 1. Описание программ и результаты проверок

### 1.1 Нормализация строк (`normaline.py`)
Программа удаляет лишние пробельные символы, оставляет ровно по одному пробелу между словами и выводит статистику по длине и количеству слов.

**Результаты тестирования:**
* **Вход:** `" Один   два "`
  * **Результат:** `Один два`
  * **Статистика:** количество слов — `2`, длина результата — `8`
* **Вход:** `""` (пустая строка)
  * **Результат:** `""`
  * **Статистика:** количество слов — `0`, длина результата — `0`

---

### 1.2 Проверка на палиндром (`palindrome.py`)
Программа определяет, является ли введенная строка палиндромом (читается одинаково слева направо и справа налево без учета регистра и знаков препинания).

**Результаты тестирования:**
* **`"А роза упала на лапу Азора"`** → **Да** (палиндром)
* **`"а"`** → **Да** (палиндром)
* **`"   "` (строка из пробелов)** → **Нет текста**
* **`"Python"`** → **Нет** (не палиндром)
* **`"А!"`** → **Нет** (по принятым правилам очистки символов)

---

### 1.3 Замена символов (`replace.py`)
Программа подсчитывает количество вхождений двоеточия `:` и заменяет его на дефис `-`.

**Результаты тестирования:**
* **Вход:** `"a::b:"`
  * **Результат:** `"a--b-"`
  * **Количество замен:** `3`
* **Вход:** `"abc"`
  * **Результат:** `"abc"` (без изменений)
  * **Количество замен:** `0`

---

### 1.4 Индивидуальный вариант 6 (`variant.py`)
Программа очищает слова от краевых знаков препинания `.,!?;:`, переводит их в нижний регистр и отбирает слова, соответствующие условию **«Длина равна 4»**.

**Результаты тестирования:**
* **Контрольный текст 1:** `"Анна, армия! Я читаю. Книга, край, рама.."`
  * **Результат:**
    ```text
    анна
    край
    рама
    3
    ```
* **Контрольный текст 2:** `"Анна, армия! Я читаю."`
  * **Вариант 1 (Начинается с 'а'):** `анна`, `армия` | Количество: `2`
  * **Вариант 2 (Заканчивается на 'я'):** `армия`, `я` | Количество: `2`
  * **Вариант 3 (Длина >= 5):** `армия`, `читаю` | Количество: `2`
* **Дополнительная проверка 1 (Пустая строка `""`):**
  * **Результат:** `Нет совпадений`, количество `0`
* **Дополнительная проверка 2 (Строка со знаками ` "!!!" `):**
  * **Результат:** `Нет совпадений`, количество `0` (так как после `.strip(".,!?;:")` не остается букв)

## 2. Теоретическая часть (Защита работы)

### 2.1 Неизменяемость строк (Immutability)
В Python строки являются **неизменяемыми объектами (immutable)**. Это означает, что после создания строкового объекта в памяти его содержимое нельзя изменить direct-методами. 
* Любые операции над строками (например, `replace()`, `strip()`, `lower()`, `join()`) **не меняют исходную строку**, а возвращают **новый объект строки** с измененным содержанием.

### 2.2 Отличие слова от подстроки
* **Слово** — это самостоятельная лексическая единица текста, выделенная с обеих сторон пробелами или знаками препинания (например, в строке `"край рамы"`, слова — это `край` и `рамы`).
* **Подстрока** — это непрерывная последовательность символов внутри исходной строки, которая не обязательно совпадает с границами слова. Например, для строки `"край"` подстроками будут `"кр"`, `"ра"`, `"й"`, `"край"`.

### 2.3 Почему правила обработки пунктуации нужно задавать ДО написания программы?
1. **Предотвращение ошибок краевых значений:** Если не определить заранее список удаляемых знаков (например, `.,!?;:`), слова вроде `"армия!"` и `"армия"` будут восприниматься алгоритмом как два разных слова или слова разной длины (6 символов против 5).
2. **Корректность фильтрации:** Проверка условий (например, `len(word) == 4` или `word.endswith('а')`) даст ложноотрицательный результат, если на концах слова останутся знаки препинания.
3. **Обработка пустых строк:** Удаление пунктуации может превратить отдельный токен (например, `"!!!"`) в пустую строку `""`. Алгоритм должен заранее учитывать этот шаг, чтобы корректно пропустить его через `if not word: continue`.
